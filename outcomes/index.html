Feature: Links

Links are supported in Notes fields and list items. When links exist in a Notes field, tappable versions are shown below the notes. When a list item’s Notes field is a URL, the text is clickable. Choosing Paste link from the list item’s menu grab’s the destination’s title and uses it for the list item in addition to pasting the link in the Notes.

Feature: Deep links

All tasks, outcomes, lists, and areas are deep link-able. Tapping Link → Copy from their respective menus copies a link to that item, e.g., outcomes://list/2DDE193F-D56A-4BC5-8693-03A5EE3A2747.
